## 运行

项目依赖已安装时：

```powershell
# 轻量 CAD 网格随仓库提供，无需本地 STEP 转换

# 开发：http://127.0.0.1:5217/actual.html
npm run dev:actual -- --port 5217 --strictPort

# 独立生产构建与预览：http://127.0.0.1:5218/actual.html
npm run build
npm run build:actual
npm run preview:actual -- --port 5218 --strictPort
```

独立构建需要现有 `dist/index.html`。构建脚本将原 `dist/` 逐字节复制到 `dist-actual/`，作为页面中“原演示”链接的离线入口，不重新构建或写入原 `dist/`。预览根地址 `/` 因此仍是原演示，新动画请访问 `/actual.html`。

## 工艺与动画

设备名称唯一来源为 `scripts/cad-process.json`，坐标与包围尺寸取自 `src/actual/cad-layout.json`（毫米转换为米）。后者记录当前 STEP 快照的装配位置，后续更换 STEP 必须同步核对映射。

| 路段 | 动作 |
| --- | --- |
| E06 → E17 | 上料爬坡、瓶流经过第一台分选机 |
| E17 → E02 / E03 | 三色 PET 与杂瓶经风送分别进入中转料仓 |
| E03 → E07 → E14 | 杂瓶爬坡、人工平台分出大白、小白、花乙、油壶、易拉罐 |
| E02 → E11 → E12 → E09 → E18 | 螺旋上料、脱标、再爬坡、第二台分选 |
| E18 → E04 | 3A 经风送进入成品仓 |
| E18 → E16 / E15 | 其余瓶料沿输送带经过并联机械手，分出绿瓶和棕瓶 |
| E16 → E05 | 剩余杂色 PET 经风送进入另一个成品仓 |
| E04 / E05 → E08 → E10 → E13 | 阈值放料、共用输送带、链板机供料、压缩与出包 |
| 独立小仓位 → E13 | 人工推车转运，预约同一打包资源 |

动画层包含瓶体移动、风送路径、输送节拍标记、螺旋/脱标旋转提示、机械手抓取投放和复位、料仓积料与门板开合、人工动作及转运、压缩板和打包块。完整 CAD 是静态底模，内部机械运动采用独立示意构件，不把合并后的整台设备当作真实关节旋转。

## 仿真行为

- 0.1 秒固定步长；场景逐帧读取状态，面板约每 0.12 秒更新，参考原项目的时钟与显示分离模式。
- 连续进料、确定性材质序列；所有来料始终有身份，进入缓冲仓、小仓位、转运、压缩或成品，不执行强制消失或班末清场。
- 四个大仓容量为演示用 72 批，小仓位为 24 批；成品仓默认 18 批申请打包，小仓位默认 6 批申请人工转运。
- 输送路段有有限缓存，料仓满或下游停用时形成等待并向上游传递。达到输入缓存上限时停止接收新的可视批次。
- E04/E05 共用单一打包任务，按达到阈值先后顺序排队；任一时刻只允许一个自动仓门打开。人工转运也占用此任务，不与自动供料混用。
- E08/E10/E13 或当前供料仓停用时暂停任务并关闭仓门。打包任务内物料始终保持同一品类。
- 并联机械手每次处理一个单元，投放后复位，复位期间不接新抓取。
- 参数、设备启停按当前步记录；拖动时间轴按历史指令重放。重置清除干预。
- 1/2/4/8 倍播放；隐藏标签页不推进、不追赶。遵守系统减少动态偏好，初始可为暂停。
- 演示窗口为 6 分钟，终点暂停并保留现场。点击重播重新从起点演示，不冒充连续班次的自然闭合。

## 真实数据与边界

模型几何和设备对应来自用户资料。输入比例、带速、识别与动作时长、容量、阈值、人工搬运时间均为示例，不是现场测量值。可视瓶代表模拟批次，未换算吨位、真实单瓶数量或生产能力。

人工小仓位和推车路径为示意，不表示已确认的地面布置或可通行路线；风送轨迹按模型锚点布置，未做气固流体计算。人工分拣后的剩余料和标签不表现。分选默认按已知材质正确分流，未引入检测误差模型。实际机械关节轴、联锁电气、PLC、传感器、物理碰撞均未接入或验证。
